# L2J4Team: HellBound
![Screenshot 1](https://i.imgur.com/MAuPJrp.png)   

Base: L2JServer 
Java: 25  
Banco de dados: MariaDB 10+  

Este é um servidor L2J buscando adicionar várias melhorias e correções, voltado para quem quer contribuir e evoluir o projeto.  

> Vamos movimentar isso! Estou voltando a mexer com L2 depois de anos, então qualquer ajuda é bem-vinda.  
> O objetivo é que todos possam colaborar mantendo forks separados, e enviar contribuições que todos possam utilizar.


## Como Contribuir

1. Faça fork do projeto no GitHub.  
2. Crie seu branch para alterações ou melhorias.  
3. Envie pull requests com suas contribuições.  
4. Mantenha o fork atualizado para facilitar a integração com o projeto principal.
